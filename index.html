Semana 2: Serialización y Protocolos

¿Qué se hizo?

Creación de modelos de datos mediante Pydantic definiendo InputSchema (datos crudos) y OutputSchema (datos transformados).

¿Cómo se hizo?

"Implementamos la herencia de BaseModel para tipificar cada variable (ej: Edad as int, Ingresos as float). Esto permite que el protocolo HTTP reconozca los datos en formato JSON automáticamente."

Impacto en el Proyecto

  • Cero errores de tipo: La base ya no acepta strings donde deben ir números.
  • Contrato de Datos: El frontend sabe exactamente qué respuesta recibirá del backend.

Semana 4: Transición a FastAPI

¿Qué se hizo?

Refactorización del código de Flask a FastAPI, aprovechando la asincronía y el tipado moderno de Python 3.10+.

¿Cómo se hizo?

"Migramos los decoradores de ruta y aplicamos validación estricta. FastAPI genera automáticamente la documentación en /docs (Swagger), facilitando las pruebas de integración."

Impacto en el Proyecto

  • Velocidad: Reducción en los tiempos de respuesta del endpoint de limpieza.
  • Auto-documentación: Reducción del 50% en tiempo de manuales técnicos para el equipo.

Semana 5: Validación Avanzada

¿Qué se hizo?

Implementación de reglas de negocio complejas mediante Field y validator de Pydantic.

¿Cómo se hizo?

"Añadimos restricciones lógicas: La edad debe estar entre 18 y 90 años, y el monto del crédito no puede ser negativo. Cada campo fue enriquecido con description para el esquema OpenAPI."

Impacto en el Proyecto

  • Seguridad Lógica: Se evitan registros incoherentes (como personas de -5 años o ingresos de $0) que dañarían el modelo de IA.
  • Calidad de Datos: El dataset resultante es 100% confiable para el entrenamiento de modelos predictivos.
